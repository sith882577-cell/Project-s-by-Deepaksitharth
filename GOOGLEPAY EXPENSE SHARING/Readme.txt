GOOGLEPAY EXPENSE SHARING using PyCharm 2026.1

Core Features:

Add, split, and track expenses among multiple users.
Implement equal and custom split functionalities.
Maintain a transaction history for each user.

DESCRIPTION:

		This program is a small tool for calculating and settling shared expenses among friends. this program modified to the google pay expense sharing video.


FUNCTIONS:
add_expense - amount splitting
view_history - record to maintaining the history for the transaction and viewing
calculate_settlements - calculate the amount for settlement
display_settlements - paid or not paid to display to the per person settlements
suggest_payments - minimum number of payments needed to settle everyone up. Instead of everyone paying everyone else, it finds the simplest way
